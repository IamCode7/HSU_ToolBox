## 주요 기능

| 기능          | 설명                                        |
| ------------- | ------------------------------------------- |
| 📝 메모        | 상단바에서 바로 여는 마크다운 메모장        |
| 📅 디데이      | 시험·발표 날짜를 최대 3개까지 상단바에 표시 |
| ⏳ 남은 기간   | 강의 영상과 과제 마감까지 남은 기간 표시    |
| 📊 시청 진도   | 강의 영상을 얼마나 봤는지 표시              |
| ✅ 할 일 개수  | 아직 끝내지 않은 강의·과제 개수             |
| ▶️ 미시청 영상 | 아직 보지 않은 영상을 한 창에 모아 보기     |
| 🗓️ 과제 달력   | 마감일을 달력으로 한눈에 확인               |

> [!TIP]
> 쓰지 않는 기능은 도구 메뉴에서 하나씩 끌 수 있다.



## 설치

[Chorme Web Store](https://chromewebstore.google.com/detail/ceflinnfnijdfpncaaelgjmieknjbabj?utm_source=item-share-cb) 에서 설치한다.



## 직접 설치

1. 이 저장소에서 **Code → Download ZIP**으로 받아 압축을 푼다.
2. 크롬 주소창에 `chrome://extensions`를 입력하고 오른쪽 위 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 압축 푼 폴더를 선택한다.



## 기술 스택

- 순수 JavaScript + CSS (빌드 없이 바로 동작)
- Chrome Extension Manifest V3
- 메모 에디터: Tiptap (ProseMirror)
